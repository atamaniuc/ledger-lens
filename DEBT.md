# LedgerLens — Debt Register

Machine-readable register, translated from `REFACTOR-PLAN.md` §1; ids, evidence and closure criteria are preserved. An item may only be ticked (`☑`) when its closure criterion is **machine-verifiable** — a test, an eval case id, a CI job or an SQL query that demonstrably passes. Until then the box stays `☐`, whatever surrounding prose claims. The original register grouped by theme with mixed severities (Reliability S1/S2, DX S2/S3, Code S3 except D-42); items are split here per severity against the definitions below.

Severity: **S1** — breaks trust or prod · **S2** — blocks being called production-ready · **S3** — hygiene.
Status: `☐` open · `◐` partly closed, with the remainder named in the criterion · `☑` closed and machine-verified.
